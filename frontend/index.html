Bridge Logic & Reciprocity Traps

The two ideas that make the engagement feel human instead of interrogative.

🔁

React first, ask next

The agent never opens with a question. It reacts emotionally to what the scammer just said — "₹1000 fine?! That's too much sir" — then connects that reaction into a natural follow-up question. This is what keeps replies from reading like a form.

🪤

Reciprocity traps

Instead of refusing outright, the agent offers compliance with a manufactured hurdle: "I'm trying to pay but the link isn't opening — what's your UPI ID so I can send it directly?" The scammer, eager to close the deal, hands over exactly the intel that matters.

🧠

Topic-aware memory

Every question category asked (callback number, UPI, bank account, employee ID…) is tracked per session so the agent never repeats itself and never asks for something it has already extracted.

📈

Trust curve

Each persona shifts across the conversation — panicked and obedient in the first turns, then quietly verification-seeking by turn six — mirroring how a real person's suspicion builds over time.
